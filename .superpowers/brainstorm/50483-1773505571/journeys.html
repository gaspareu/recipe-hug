Section 1 — Parcours utilisateurs à évaluer

6 parcours couvrant l'usage famille + partage. Est-ce que tous ces parcours sont pertinents ?

J1

Créer une recette via le chat IA

Home → prompt → recette générée → confirmation → sauvegarde → fiche recette

J2

Ajouter une recette manuellement / depuis une photo

Dashboard → upload image ou saisie manuelle → édition → sauvegarde

J3

Cuisiner une recette

Dashboard → sélection recette → fiche détail → liste ingrédients → mode étape par étape → assistant cuisson

J4

Planifier les repas de la semaine

Home ou nav → Meal Planning → sélection recettes → validation du plan

J5

Partager une recette

Fiche recette → partage → destinataire reçoit → claim → recette dans son compte

J6

Retrouver une recette existante

Dashboard → recherche / filtre (saison, statut, favoris) → accès fiche

Clique pour désélectionner les parcours non pertinents, ou laisse tout sélectionné si les 6 sont bons. Réponds dans le terminal quand tu es prêt.
